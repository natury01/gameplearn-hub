## ชุดทดสอบ SQL (`sql/t_sql.sh`)

ตั้ง Postgres 16 ขึ้นมาแล้ว **จำลองสภาพ Supabase** ก่อนรันไฟล์จริง:
`auth.uid()` · role `anon`/`authenticated` · RLS ชุดเดียวกับของจริง ·
และ **จงใจวาง pgcrypto ไว้ในสคีมา `extensions` ไม่ใช่ `public`**
เพราะนั่นคือต้นเหตุที่ทำให้ `supabase_patch_all_v7993.sql` ล้มทั้งไฟล์บนฐานจริง
ทั้งที่รันผ่านบน PG เปล่า (`function crypt(text, text) does not exist`)

สิ่งที่พิสูจน์: ห้องของครูคนอื่นไม่รั่ว · ห้อง "โค้ดเท่านั้น" ไม่โผล่ · ไม่มีชื่อนักเรียน/โค้ดห้องหลุด ·
คนที่ยังไม่ล็อกอินทำอะไรได้/ไม่ได้บ้าง · กุญแจรับห้องใช้ซ้ำไม่ได้ · ห้องที่มีเด็กแล้วไม่ถูกเก็บกวาด

ไม่มี Postgres บนเครื่อง = ชุดนี้ **ข้ามให้เอง** ไม่ทำให้ชุดอื่นตก

## กับดักที่เคยเสียเวลาไปแล้ว

- `document.body.textContent` **ลากเนื้อในแท็ก `<script>` มาด้วย** — จะเจอคำที่อยู่ในโค้ด
  ทั้งที่หน้าจอไม่ได้แสดง · ให้อ่านจาก `#page-main` หรือ `#content` แทน
- ตั้งค่า `localStorage` **หลัง** `goto()` แล้วเปลี่ยนแค่ `#hash` เบราว์เซอร์ไม่โหลดหน้าใหม่
  `boot()` จึงไม่ทำงานอีกรอบ · ใช้ `page.addInitScript()` ฝังเซสชันก่อนหน้าจะเริ่มรัน
- 404 ของภาพหรือของตารางที่ยังไม่ได้สร้าง **ไม่ใช่บั๊ก** — ชุดนี้จงใจให้เกิด
  ใช้ `realErrors()` ที่นับเฉพาะสคริปต์พังจริง ไม่ใช่ `console.error` ทุกบรรทัด
