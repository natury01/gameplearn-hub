## เงื่อนไขการรันที่ต้องรู้

| เรื่อง | รายละเอียด |
|---|---|
| **Postgres** | ชุด SQL ต้องมีเซิร์ฟเวอร์ในเครื่อง · ตั้ง `GP_PGHOST`/`GP_PGPORT`/`GP_PGUSER` (ดูเอกสาร 80) · ถ้าลืมตั้ง ตั้งแต่ V.1.6.7 ชุดจะ**ลองต่อ 127.0.0.1 พอร์ต 5432/5433 ให้เองก่อน** แล้วค่อยยอมข้าม — กันเขียวหลอกบนเครื่องที่มี Postgres อยู่แล้ว |
| **ภาษาไทยกับ psql (2)** | [V.1.6.17] `psql` บน Windows ไทยยัง **เดา client encoding เป็น WIN874** จากโค้ดเพจของระบบ ⇒ อ่านไฟล์ SQL/fixture ที่เป็น UTF-8 แล้วล้มที่ตัวอักษรไทยตัวแรกที่อยู่นอกช่วง cp874 (`byte sequence 0x81 in encoding "WIN874"`) · ชุดทดสอบตั้ง `PGCLIENTENCODING=UTF8` ให้เองแล้ว ไม่ต้องจำเอง |
| **ภาษาไทยกับ psql** | `psql.exe` บน Windows ที่ระบบไม่ใช่ UTF-8 codepage (เช่นไทย = 874) แปลง argument ของ `-c` เป็น ANSI แล้วส่งไบต์ผิด ⇒ ตั้งแต่ V.1.6.7 ชุดส่ง SQL ทาง **stdin** ผ่านฟังก์ชัน `gpq()` แทน และมี **"นกขมิ้น"** ตรวจก่อนเริ่มทุกครั้ง ถ้าท่อส่งไทยไม่ได้จะหยุดพร้อมบอกวิธีแก้ ไม่ปล่อยให้แดงเป็นร้อยข้อโดยไม่รู้สาเหตุ |
| **playwright** | ต้องมีในเครื่อง (`npm i playwright && npx playwright install chromium` ในโฟลเดอร์นี้) หรือมี `node_modules` ที่โฟลเดอร์แม่ · ชี้เบราว์เซอร์เองได้ด้วย `GP_CHROMIUM` |

## สัญญา exit code (STD-006 ข้อ 1)

| รหัส | ความหมาย |
|---|---|
| `0` | รันครบและผ่านทุกข้อ |
| `1` | มีข้อตก หรือรันไม่สำเร็จ (แดง) |
| `77` | **ข้ามทั้งชุด ไม่ได้ตรวจอะไรเลย** (ธรรมเนียม Automake/Meson) — ตัวรันนับแยก ห้ามนับเป็นผ่าน |

**ห้ามคืน "จำนวนข้อที่ตก" เป็น exit code** — เกิน 255 จะวนกลับเป็น 0 (แปลว่าผ่าน!) และอาจชนรหัส 77

## บทเรียนที่ทะเบียนนี้เกิดขึ้นมาเพื่อกัน

1. **"ข้าม" ถูกกลืนเป็น "ผ่าน"** — ก่อน V.1.6.7 ชุด SQL ข้ามแล้ว `exit 0` ทำให้บรรทัดสุดท้ายพิมพ์ "ผ่านครบทุกชุด" ทั้งที่เพิ่งขึ้นป้าย "ข้าม ≠ ผ่าน" ไปสองบรรทัดก่อนหน้า
2. **ชุดที่รัน 0 ข้อเคยรายงานเป็นเขียว** — `ผ่าน 0/0 ข้อ` อ่านแล้วเข้าใจว่าผ่าน · ตั้งแต่ V.1.6.7 นับเป็นแดง
3. **ไฟล์เทสต์ที่ไม่มีใครเรียก** — รายชื่อชุดใน `run-all.sh` เป็นรายการตายตัว ถ้าเพิ่มไฟล์ใหม่แล้วลืมใส่ จะหายไปเงียบ ๆ · ตั้งแต่ V.1.6.7 มียามเทียบกับไฟล์จริงในโฟลเดอร์แล้วเตือน
4. **ตัวเลขในเอกสารค้าง** — `test/README.md` เคยเขียน 514 ข้อ ขณะของจริง 543 · เลขที่เชื่อได้คือเลขที่**ตัวรันพิมพ์เอง** ไม่ใช่เลขในเอกสาร และไม่ใช่การนับสัญลักษณ์ ✅ (ซึ่งจะเกินจริงเพราะนับบรรทัดสรุปด้วย)
