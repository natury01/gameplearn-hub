# เกมเพลิน (GamePlearn) — เว็บกลาง

**Game On. Learn Beyond.** — เริ่มเกม แล้วก้าวไปไกลกว่าการเรียนรู้เดิม

ศูนย์รวมเกมการเรียนรู้สำหรับโรงเรียนไทย · https://gameplearn.com
repo นี้คือ **เว็บกลาง** เท่านั้น ตัวเกมแต่ละเกมอยู่คนละ repo

## เอาขึ้นเว็บยังไง

ทั้ง repo เป็นไฟล์นิ่ง (static) ไม่มีขั้นตอน build ไม่ต้องติดตั้งอะไร
อัปโหลดทุกไฟล์ขึ้น GitHub repo `gameplearn-hub` แล้ว Cloudflare Workers จะ deploy ให้เอง

รายละเอียดทีละขั้นอยู่ใน **`README_DEPLOY.md`**

> ⚠️ อัปโหลด **ทุกไฟล์** รวมโฟลเดอร์ `css/` และ `js/` ด้วย
> อัปเฉพาะ `index.html` หน้าเว็บจะขึ้นแต่ไม่มีสีและกดอะไรไม่ได้

## กฎ 3 ข้อที่ห้ามพลาด

**1. `js/gp-join.js` เป็นไฟล์สาธารณะ — เกมทุกเกมโหลดไฟล์นี้**
แก้แล้วกระทบทุกเกมพร้อมกัน ห้ามเปลี่ยนชื่อไฟล์ ห้ามเปลี่ยนพฤติกรรมโดยไม่แจ้งแชตเกม

**2. คีย์ localStorage ต่อไปนี้จองไว้ให้เว็บกลาง — เกมห้ามใช้ซ้ำ**

```
gp_hub_sess · gp_join_handoff · gp_brand_cache · gp_theme · gp_announce_off
```

ทุกเกมอยู่โดเมนเดียวกัน `localStorage` แยกตามโดเมนไม่ได้แยกตาม path
คีย์ชนกัน = เซฟนักเรียนพังข้ามเกม (เคยเกิดขึ้นจริงแล้ว)

**3. ใส่ได้เฉพาะ anon key เท่านั้น**
`js/config.js` เปิดอ่านได้จากเบราว์เซอร์ทุกคน สิทธิ์จริงคุมด้วย RLS ฝั่ง Supabase
ห้ามใส่ service role key เด็ดขาด

## ข้อความบนเว็บแก้จากไหน

เกือบทุกข้อความแก้ได้จาก **หน้า Admin** โดยไม่ต้องแก้โค้ดและไม่ต้อง deploy ใหม่:
โลโก้ · ไอคอนแท็บ · ธีมและชุดสี · สโลแกน · ประกาศบนหัวเว็บ ·
ข้อความหน้าสนับสนุน · QR · ทะเบียนเกม (ชื่อ คำอธิบาย ปก กลุ่มสาระ สมรรถนะ) · คำถามที่พบบ่อย

ค่าทั้งหมดเก็บในตาราง `site_settings` ของ Supabase
ยังไม่ได้ตั้งค่า → เว็บใช้ข้อความมาตรฐานที่เขียนไว้ใน HTML ไม่มีอะไรพัง

## ต้องรัน SQL อะไรก่อน

เว็บนี้ทำงานคู่กับฐานข้อมูล Supabase · ไฟล์ SQL อยู่ในชุด **PLATFORM PACK** (คนละโฟลเดอร์)
ลำดับและคำอธิบายอยู่ใน `README_FIRST.md` ของชุดนั้น

เว็บออกแบบให้ **ทนต่อการที่ยังรัน SQL ไม่ครบ** — ส่วนที่ยังไม่มีตารางรองรับจะถอยไปใช้ข้อมูลเท่าที่มี
และขึ้นข้อความบอกว่าต้องรันไฟล์ไหน ไม่ใช่หน้าจอขาว
