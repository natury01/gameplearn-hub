ชุดการเรียนรู้ดิจิทัลรูปแบบเกม วิชาสังคมศึกษา/ประวัติศาสตร์ท้องถิ่น สำหรับนักเรียนชั้น ป.4
พัฒนาโดย นายอาคม อินต๊ะพันธ์ — เผยแพร่ที่ https://cai-kan.pages.dev

## เวอร์ชันปัจจุบัน

- เกม: **V.7.99.33-IX2050-2569.71**
- Dashboard ครู: อยู่ในไฟล์เดียวกับเกม และถูกสกัดออกมาเป็น `dashboard.html` ตอนสร้างไฟล์ชุดนี้
- แพตช์ฐานข้อมูลที่คู่กับเวอร์ชันนี้: `supabase_patch_all_v7995.sql`

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (ไฟล์เดียวจบ — ฉาก ข้อสอบ เสียง ระบบห้องเรียน และ Dashboard ฝังอยู่ข้างใน) |
| `dashboard.html` | หน้าครูแบบแยกไฟล์ สำหรับเปิดตรงโดยไม่ต้องผ่านตัวเกม |
| `img/` | ภาพหน้าจอรายด่าน ใช้ทำสไลด์บนการ์ดเกมของเว็บกลาง (เอกสาร 58) |

ทั้งสองไฟล์เป็น HTML ไฟล์เดียวจบ ไม่มี build step ไม่มี dependency ภายนอกที่ต้องติดตั้ง

## หลังบ้าน

**Supabase** (โปรเจกต์ `janoonnhzpwjnxqjvswt`) เป็นที่เก็บข้อมูลทั้งหมด — ห้องเรียน รายชื่อนักเรียน
คะแนนรายข้อ เซฟเกม สื่อห้องเรียนรู้ ตัวชี้วัด และสิทธิ์ผู้ดูแล

Google Apps Script / Google Sheets **ถูกตัดออกจากตัวเกมแล้ว 100%** ตั้งแต่เฟส 3e
(ไฟล์ `Code.gs` เก็บไว้เพื่อย้ายข้อมูลเก่าเท่านั้น ไม่มีการเรียกใช้ระหว่างเล่น)

คีย์ที่ฝังใน `index.html` เป็น **anon key** ซึ่งปลอดภัยตามการออกแบบของ Supabase (ถูกจำกัดสิทธิ์ด้วย RLS)
— service_role key ห้ามอยู่ในไฟล์นี้เด็ดขาด

## การนำขึ้นใช้งาน

1. เปิด Supabase → SQL Editor → วางไฟล์ `supabase_patch_all_v7995.sql` ทั้งไฟล์ → Run (รันซ้ำได้ ไม่เสียข้อมูล)
2. อัปโหลด `index.html` · `dashboard.html` **และโฟลเดอร์ `img/` ทั้งโฟลเดอร์** ขึ้น Cloudflare Pages
   (ถ้าลืม `img/` เว็บกลางจะได้ลิงก์ภาพที่เปิดไม่ได้ — เกมตรวจก่อนส่งอยู่แล้วและจะไม่ส่งให้ แต่การ์ดก็จะไม่มีสไลด์)
3. เข้าหน้าครู → เข้าสู่ระบบด้วย Google → สร้างห้องเรียน → แจกโค้ดหรือลิงก์ `?join=CODE` ให้นักเรียน

### ⚠️ ถ้าย้ายโดเมน ต้องเปิดหน้าห้องเรียนหนึ่งครั้งจากที่อยู่ใหม่

เกมส่ง **ที่อยู่ภาพรายด่าน** ขึ้นเว็บกลาง โดยคิดจากที่อยู่ของหน้าที่เปิดอยู่ตอนนั้น
และเว็บกลาง **เก็บสตริงที่อยู่นั้นลงฐาน** ⇒ วันที่ย้ายโดเมน ลิงก์ในฐานยังชี้โดเมนเก่า
จนกว่าจะมีคนเปิดหน้าห้องเรียนอีกครั้งจากที่อยู่ใหม่ (รอบเดียวจบ เพราะเป็นการแทนที่ทั้งชุด)

**ถ้าปิดโดเมนเก่าไปก่อนทำข้อนี้** การ์ดเกมบนหน้าแรกของเว็บกลางจะถอยไปใช้ภาพปกเดิมเงียบ ๆ
จึงควรทำตามลำดับ: อัปโหลดที่อยู่ใหม่ → เปิดหน้าห้องเรียนหนึ่งครั้ง → ค่อยปิดที่อยู่เก่า

## ลิงก์พิเศษ (สำหรับครู)

| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `?join=CODE` | เปิดเกมพร้อมกรอกโค้ดห้องให้อัตโนมัติ — ส่งลิงก์นี้ให้นักเรียนได้เลย |
| `?demo=1` | โหมดสาธิต: เล่นได้ทุกอย่าง เหรียญเต็ม ปลดล็อกครบ แต่**ไม่บันทึกคะแนน ไม่ขึ้นกระดานอันดับ** |
| `?admin=1` | เปิดเมนูเข้าสู่ระบบสำหรับครู (หรือแตะป้ายเวอร์ชันมุมซ้ายล่างหน้าแรก 5 ครั้ง) |
| `?dev=1` | เมนูข้ามด่าน + มาตรวัด FPS สำหรับตรวจงานระหว่างพัฒนา |

## หมายเหตุสำหรับผู้ดูแลโค้ด

- ไฟล์ชุดนี้ **สร้างด้วย `python3 build_repo.py`** อย่าแก้ `repo/index.html` หรือ `repo/dashboard.html` โดยตรง
  — แก้ที่ `game.html` แล้วสั่ง build ใหม่ (เลขเวอร์ชันใน README นี้ดึงจาก `GAME_VERSION` อัตโนมัติ)
- ข้อความข้อสอบเป็นเครื่องมือวิจัย **ห้ามแก้โดยไม่ได้รับคำสั่ง**
- ข้อมูลที่บันทึกใช้ `logId` เดิมเสมอแม้เปลี่ยนรูป/ไอคอน เพื่อให้ข้อมูลวิจัยต่อเนื่อง
